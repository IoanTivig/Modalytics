# Controls and shortcuts

## Navigating (any tool)

| Input | Action |
| --- | --- |
| Mouse wheel, <kbd>+</kbd> / <kbd>−</kbd>, <kbd>Ctrl</kbd>+<kbd>+</kbd> / <kbd>Ctrl</kbd>+<kbd>−</kbd> | Zoom about the cursor |
| Middle drag, right drag | Pan |
| <kbd>Ctrl</kbd> + middle drag | Move the image under the cursor (its masks follow) |
| Right click (without moving) | Settings of the image, mask or object under the cursor |
| <kbd>F</kbd> / <kbd>1</kbd> | Fit all / one image pixel per screen pixel |
| Minimap (bottom right) | Click or drag to jump there |
| <kbd>Shift</kbd>+click, <kbd>Shift</kbd>+drag | Add the layer under the cursor / the images a rectangle touches to the selection |
| <kbd>Esc</kbd> | Cancel what the tool is doing, then clear the selection |

A graphics tablet's pen side button held while moving pans; its dial zooms.

## While drawing and editing

| Input | Action |
| --- | --- |
| <kbd>Alt</kbd> (held) | Subtract instead of add |
| <kbd>[</kbd> / <kbd>]</kbd> | Brush and eraser size |
| <kbd>Enter</kbd>, double-click | Close the polygon |
| <kbd>Backspace</kbd> | Remove the polygon's last point |
| <kbd>1</kbd>–<kbd>9</kbd> | Give the selected objects (Select) or the suggestion (Review) the group's n-th grade |
| <kbd>Delete</kbd> | Delete the selected objects, points or suggestion |
| Arrow keys (<kbd>Shift</kbd>: × 10) | Nudge the selected points (Edit points) |
| <kbd>S</kbd> | Simplify the outline (Edit points) |

## Reviewing and registering

| Input | Action |
| --- | --- |
| <kbd>Enter</kbd> | Accept the suggestion (Review); start the search (Register) |
| <kbd>Tab</kbd> / <kbd>Shift</kbd>+<kbd>Tab</kbd> | Next / previous suggestion or candidate |
| <kbd>Ctrl</kbd>+<kbd>Enter</kbd> | Accept all on the image (Review); segment the whole image (Segment) |

| <kbd>Ctrl</kbd>+<kbd>I</kbd> | Import images… |
| <kbd>Ctrl</kbd>+<kbd>M</kbd> | Measure |
| <kbd>Ctrl</kbd>+<kbd>Z</kbd> / <kbd>Ctrl</kbd>+<kbd>Y</kbd> | Undo / redo |
| <kbd>Ctrl</kbd>+<kbd>,</kbd> | Settings |

In the Help window: <kbd>Ctrl</kbd>+<kbd>F</kbd> searches, <kbd>Alt</kbd>+<kbd>←</kbd> / <kbd>Alt</kbd>+<kbd>→</kbd>
go back and forward.
